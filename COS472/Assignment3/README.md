How to run kMeans.ky:

    run program with a string formatted List[List[float]]

    general case:
        python3 kMeans.py "[[x_1,x_2,x_3,...,x_n],[y_1,y_2,y_3...y_n]...]"

    example:
        python3 kMeans.py "[[1,1,1],[1,3,1],[2,2,2],[4,2,2],[3,1,2],[2,3,1],[4,4,4],[3,4,2]]"
